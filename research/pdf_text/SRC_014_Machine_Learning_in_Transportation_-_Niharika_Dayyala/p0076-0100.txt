Example of application of Bayes’ theorem: Let’s consider a
transportation-related example where we want to estimate the
probability of a person using a certain mode of transportation given
their age category. For example, Bayes’ theorem is used to update
the probability estimate based on age category. The example
shown in →Figure 2.14 calculates the posterior probability of a
person using a car given their age category (see the output at the
bottom of the figure).
  % Sample data

  ageCategories = {'Young', 'Adult', 'Senior'};
  transportationModes = {'Car', 'Bus', 'Train',

  'Walking', 'Biking'};

  % Prior probabilities P(Transportation Mode)
P_Transportation = [0.4, 0.2, 0.1, 0.2, 0.1]; % Adjust

  as needed
  % Conditional probabilities P(Age Category | Transportation Mode)

  % Example values, adjust based on your scenario

  P_Young_given_Mode = [0.6, 0.2, 0.1, 0.05, 0.03];
  P_Adult_given_Mode = [0.3, 0.5, 0.2, 0.1, 0.05];
  P_Senior_given_Mode = [0.1, 0.3, 0.5, 0.2, 0.1];

% Age distribution in the population (prior probability of age category)

  P_Young = 0.3;
  P_Adult = 0.5;
  P_Senior = 0.2;

  % Bayes' theorem: P(Mode|Age) = (P(Age|Mode) * P(Mode)) / P(Age)
 % where P(Age) = P(Age|Mode) * P(Mode) + P(Age|~Mode) * P(~Mode)
% Example: Calculate the posterior probability of using a Car given the

  person is Young
  modeIndex = 1; % Index of 'Car' in transportationModes

  ageIndex = 1; % Index of 'Young' in ageCategories

  P_Transportation(modeIndex)) / ...
  (P_Young_given_Mode(ageIndex) *
  P_Transportation(modeIndex) + ...
  P_Young_given_Mode(ageIndex) * (1 -
  P_Transportation(modeIndex)));

  % Display the results

  fprintf('Prior Probability of using Car (P(Car)):
  %.2f%%\n', P_Transportation(modeIndex) * 100);
