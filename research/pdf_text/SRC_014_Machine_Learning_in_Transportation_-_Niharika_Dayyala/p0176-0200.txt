5.2.4  Hierarchical Clustering

Hierarchical clustering groups the observations in a dataset into a
hierarchy of clusters. Hierarchical clustering does not need to
specify the number of clusters prior to the analysis. The hierarchical
clustering algorithm starts with each observation as its own cluster.
The algorithm then follows an iterative process and merges the
clusters into larger clusters in the later iterations. This iterative
process continues until one big cluster, called the root, is formed.

  Distance measures are used to find the similarity and
dissimilarity between the observations and between clusters. Since
distances are measured, it is a good practice to standardize the
numerical variables to convert the variables to the same scale. In
addition to the distance between observations, the merging of
clusters also requires measuring the distance between observations
and the clusters as well as the distance between clusters. The
distances between the observations are measured differently for
numerical variables and categorical variables. Euclidean distance
(distance between two observations) or Manhattan distance
(absolute distance between two observations) is used when all the
variables are numerical data. When there are categorical variables
in the dataset, Gower’s coefficient is used.

  The distance between clusters can be computed in different
ways, such as single linkage (nearest distance between two
observations in different clusters), complete linkage (farthest
distance between two observations in different clusters), average
linkage (average distance between all pairs of observations in
different clusters), centroid (distance between the centroids of two
different clusters), and the Wards (minimum variance method to
form compact clusters) method. The methods chosen for distance
computations have a great impact on the results. The best choices
in the methods are the ones that make clusters in line with the
theory or practice.
  The result of a hierarchical clustering is shown using a tree
diagram called a dendrogram. In a dendrogram, there is one big
cluster consisting of all observations on the top called the root, and
each observation is its own cluster at the bottom. As we go up the
hierarchy, the clusters are merged at different levels.

Chapter 6  Deep learning

Deep learning is a subset of machine learning, a subset of
artificial intelligence. In deep learning, the applicable concept is
that the algorithm extracts the features based on which it can
classify or regress, rather than the user having to specify them.
The goal of the ANN is to output a function that matches the
output, as given by the training data. At each of the layers (parts
of the chain structure that makes up an ANN), an approximate
function is obtained, and the learning algorithm improves the
functions until the final output matches closely with the given
information. The term “deep” refers to the depth or the size of
the chain structure that is utilized. The application of deep
learning mostly uses multiple layers in neural networks that can
extract high-level features as part of the learning process for
complex relationships between inputs and outputs. The network
architecture and the training options should be selected in a way
such that the network is progressively improved and is able to
make better predictions with new data. The basic approach
involves the use of feedforward networks (such as convolutional
networks) as well as feedback networks (such as recurrent
networks).

  The main superiority of ANN over conventional statistical
approaches such as regression is its ability to handle nonlinear
models. In ANN, the linear models are applied to nonlinear
transformation of the input functions. In the process, a nonlinear
learning algorithm is developed to provide a set of new features
or representations of the input function. The algorithm is
developed by a process called φ mapping. The technique that
separates deep learning from other machine learning models is
that the φ mapping process is “learned” rather than manually
selected or based on some generic approach. The kernel
approach is utilized to transform the given data and then
develop a linear model with the transformed data (or space). In
this process, the learning algorithm is used to write a function x
as an output of a feature function φ(x) and the dot product with
another function of x. The evaluated function may be nonlinear,
but the relationship between φ(x) and f(x) is linear.

  Two approaches to deep learning are discussed below with
examples: (1) transfer learning and (2) long short-term memory
(LSTM).
