4.2.2  Naïve Bayes’ model

Another popular machine learning algorithm is the Naïve Bayes’ algorithm,
which is based on Bayes’ theorem. The Naïve Bayes’ algorithm finds the
probability of a certain class given a set of features. Bayes’ theorem uses a
probabilistic framework and updates the probability based on new
information (→Rish, 2001). The “naive” in Naïve Bayes comes from the
assumption that features used to describe an observation are conditionally
independent, given the class label. This means that the presence or absence of
a particular feature does not affect the presence or absence of any other
feature. This assumption simplifies the calculations and makes it
computationally efficient, even though it may not always hold true in real-
world scenarios.
  Bayes’ theorem is a mathematical formula that describes the probability of
an event, based on prior knowledge that might be related to the event. The
theorem is expressed as

  P(A|B) = P(B|A) ∗ P(A)/P(B)

where P(A) is the probability of event A; P(B) is the probability of event B;
P(A|B) is the probability of event A given event B; and P(B|A) is the probability
of event B given event A.

  When there is a new set of variables, the Naïve Bayes’ algorithm will
calculate the probability of each class with the features. Finally, the class with
the highest probability is predicted.

  Advantages:

  1. Simple to understand.
  2. Can be implemented easily and can predict quickly.
  3. Requires less training data and can handle both continuous and discrete

  data.

Disadvantage:

  1. The assumption of all predictors being independent may not hold good
  at all times and hence limits the applicability of this model.

4.2.4  Decision tree

One of the effective supervised learning algorithms is a decision tree, which is
used across various domains and applications. Decision trees can handle a
wide range of data and are very proficient in predicting both categorical and
continuous variables (Breiman et al., 1984).

  Based on specific conditions, decision trees can represent solutions in a
visual form. Each node of the tree is a decision point and based on the
condition, data is split into subsets. During the training process, the algorithm
creates branches, which lead to different outcomes and thus form a
hierarchical structure. This structure allows for a clear and intuitive
understanding of the decision-making process.

  The effectiveness of decision trees can be compared based on impurity
measures. These measures or metrics serve to ensure that each split optimally
enhances the purity of the predicted variable within each subset. The accuracy
of the classification problem can be improved by maximizing the purity of the
decision trees.

  Common metrics used to quantify the impurities are entropy and
information gain (→Dash, 2022). Entropy measures the uncertainty or disorder
within a set of data, while information gain quantifies the reduction in
uncertainty achieved by splitting the data based on a particular feature. These
measures can be evaluated at each decision point; the algorithm can construct
a tree that best separates classes and minimizes classification errors.

4.2.4.1  Pruning

Like any machine learning model, overfitting is one of the problems with the
decision tree. The tree can become large while capturing the information of
the training data. When a decision tree becomes too large and complex, it
struggles to generalize well to new samples. Conversely, if the tree is too
small, it may fail to capture the intricate patterns present in the training data,
leading to poor performance. Balancing between complexity and simplicity is
crucial for building decision trees that generalize effectively (→Bradford et al.,
1998).

  Just like in the case of a big tree where we cut the branches and prune
them, “pruning” is the process of reducing the size of the decision tree to
avoid overfitting. The branch node can be converted to a leaf node, and by
removing branches of the tree, the complexity of tree can be reduced, thereby
reducing the risk of overfitting.
  Pruning makes the model focus on the important features in the dataset
and avoids the irrelevant features. In this way, it helps to develop a more
generalized and robust model that can perform well both with the training and
the new data.
