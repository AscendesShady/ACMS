7.2.5.3  Latent dirichlet algorithm (LDA)

LDA uses a probability-based approach to find clusters within
documents. LDA defines K-specified clusters and assigns a
probability for each word to belong to a cluster. It is more effective
compared to other clustering methods as it identifies hidden topics
that are not explicitly identified in the text. We use the
“topicmodels” package in R to apply the LDA technique.

  We will use the preprocessed corpus: the term document matrix
“Pdfcorpus.tdm” created in Section 7.2.2 to apply LDA and identify
the important topics within the pdf document. The LDA function
takes the document term matrix as input to identify topics. Hence,
we transform the term document matrix to create the document
term matrix to use as input for the LDA() function. A view of the
document term matrix after removing the sparse terms is shown in
Output for R Code Snippet 12a. We then apply the LDA() function on
the document term matrix to create three clusters using the Gibbs
method. We can observe the topics and the frequently occurring
terms in the topics with the terms() function as shown in Output for
R Code Snippet 12b. The number of terms can be specified as input
in the terms() function.

  Pdfcorpus.dtm=t(Pdfcorpus.tdm)
  Pdfcorpus.dtm1=removeSparseTerms(Pdfcorpus.dtm,0.99)
  View(data.frame(as.matrix(Pdfcorpus.dtm1)))
  library("topicmodels")
  LDATopics = LDA(Pdfcorpus.dtm1, method='Gibbs', k=3,
  control=list(seed=1234))
  terms(LDATopics,20)
