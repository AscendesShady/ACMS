2.3  Data cleaning

Raw data we extract from external sources is usually unclean.
Unclean data may contain missing values or outliers. Raw data also
contains several unwanted columns and rows of data. The presence
of missing values and outliers can lead to incorrect results and
experimental errors during data analysis. Missing values and
outliers must be treated with appropriate techniques before data
analysis. We must also remove unwanted variables and rows to
perform data analysis on selected data.

2.3.1  Working with missing values in R

Missing values exist in the form of blanks or NAs in the dataset. We
can identify the presence of missing values during the data
exploration stage by observing the data in the variables as well as
by using counting, sorting, and filtering techniques. If very few
records in a dataset have missing values, then we can choose to
delete these records as deleting the few records will not impact the
analysis. If several records have missing values, deleting may not be
a good choice as it can delete data from other important variables
and can reduce the sample size. In such cases, missing data is
replaced with other data such as mean and median for numerical
variables, or mode for categorical variables called “data
imputation.” Several other imputation methods exist that can be
explored.

2.4.2  Assigning bins to numeric data with R

Binning is the process of grouping numeric data into a small
number of manageable categories. Assigning bins to numerical
data is a common practice when we want to categorize numerical
values into a small number of groups. For example, if we have an
“age” column in our dataset and we want to understand the impact
of age categories on driving behavior instead of age. Such
transformations are applicable in classification methods such as
logistic regression, naïve Bayes, etc., where the outcome variable is
of type categorical. Converting to bins can also help reduce noise in
the data. Creating groups can be done by creating equal-sized bins
or user-specified bins.

  To assign bins to a column, we first decide the number of
bins/intervals we want to create. We use the cut() function to create
and assign bins to a variable as shown in R Code Snippet 28. The
cut() function assigns the group labels to the data that falls within
the upper and lower limits of intervals. In the cut() function, the
number of bins we want to create is specified in breaks. The group
labels are specified in labels. The logical values in the last two
arguments ensure that the bins assigned are mutually exclusive (no
two values are assigned the same bin label). To know the upper and
lower limit of the intervals for the groups, we use the level()
function along with the cut() function with the same options.

  range(TrafficData$VehicleMiles23)
  TrafficData$VehicleMiles23_bin <-
  cut(TrafficData$VehicleMiles23, breaks=4,labels=c("1", "2",
  "3", "4"), include.lowest=TRUE, right=FALSE)
  table(TrafficData$VehicleMiles23_bin)
  levels(cut(TrafficData$VehicleMiles23, breaks=4,
  include.lowest=TRUE, right=FALSE))
