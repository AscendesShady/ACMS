4.2.5  Linear regression

To find the linear relationship between independent and continuous
dependent variables, we can use linear regression. The purpose of linear
regression is to best fit the data and to find the parameters by minimizing the
error in prediction. Mathematically, linear regression is expressed as

  y = β0 + β1x + ε

Here, y is the dependent variable; x is the independent variable; β0 is the
intercept of the regression line; β1 is the slope of the regression line; and ε is
the error term.

  Once the model is built, there are different performance metrics used to
evaluate the model prediction. These metrics provide insights into the
relationship between the explanatory variables and how accurate the model is.
R-squared, adjusted R-squared, and RMSE are a few metrics to measure the
performance of the model.

  R-squared: R-squared represents the proportion of the variance for a
dependent variable explained by the independent variable(s).

  Adjusted R-squared: The adjusted R-squared is a modified version of the R-
squared that depends on the number of predictors. When a new variable is
added, the adjusted R-squared increases if that variable is significant and
decreases if it is not.

  RMSE: It is calculated as the square root of the mean of the squared
differences between actual outcomes and predictions.

  Assumptions:
  There are several assumptions in regression modeling (Poole et al., 1971,
Weisberg, 2005). Before interpreting the results, these assumptions are to be
checked.
  Linearity: This is one of the assumptions in regression modeling. The
relationship between independent variables and dependent variables should
be linear.
  Multicollinearity: There should not be any high correlation between the
independent variables in a regression model. The occurrence of a high
correlation between two or more independent variables or multicollinearity
can cause problems with the estimation of coefficients and the interpretation
of the model.
  Homoscedasticity: Homoscedasticity means same variance.
Homoscedasticity implies that the variability of the error term remains
constant across all levels of the independent variables. This assumption is of
significance because linear models are sensitive to outliers within the dataset,
potentially altering the regression line and consequently impacting the results.

  Normal distribution of error terms: In cases where the error terms deviate
from a normal distribution, the confidence intervals associated with regression
estimates may either widen or narrow excessively. When these intervals
become unstable, the process of estimating coefficients through least squares
minimization becomes challenging. The presence of non-normally distributed
errors implies the existence of outliers or unusual data points that warrant
closer examination to refine the model.

4.2.6  Neural network

Artificial Neural Network (ANN) as the name suggests is a network of neurons
and gained its name from their biological counterparts. It consists of a series
of connected neurons that extract patterns from the given data. Neurons are
the basic building blocks in ANN and receive weighted information from the
neurons connected to them and produce the output by passing a weighted
sum of inputs to an activation function.

  There are three types of layers in the ANN network. First is the input layer,
then a hidden layer, and then an output layer. The input layer represents the
dimensions of the input features and the nodes in this layer will pass the
inputs (features) to the hidden layer.

  Hidden layers show the relationship between input and output through
the activation function which assigns a set of weights to the inputs. Complex
computations are performed on the features that enter through the input
layer. The output layer represents the information learned by the network and
gives the output of the ANN model.

4.2.7  Gradient descent algorithm

In an ANN modeling process, there are three main parts: training, testing, and
validation. During the training process, the loss function is minimized so that
the best accuracy is achieved. Each node in the ANN will have an activation
function that can be treated like a switch for that neuron. The output of the
node is calculated based on the input and its weights. The validation and
testing are done to quantify the accuracy on another set of data that is not
being used to build the model.

  The main purpose of the optimization function is to identify the weights
that can minimize the loss function. These functions calculate the gradients
that are partial derivatives of the loss function with respect to the weights,
which get modified as the gradient is calculated. This method of continuously
evaluating the gradient and then updating the weights and bias is called
“gradient descent.”

5.1  Dimension reduction using principal
component analysis (PCA)

In problems that involve many variables, PCA is used to find the
structure within the dataset that can identify the more important
variables (dimensions). The application of PCA transforms the
variables to a lower dimensional space without losing a significant
amount of information. The application of PCA results in developing
a set of orthogonal coordinate systems (dimensions), where the
coordinates are according to the relative proportion of variance that
could be explained by the variables. One benefit is that the data
could then be visualized by plotting them into two or three
coordinate systems. The method involves standardizing the
variables. The output can be viewed as the cumulative explained
variance for the number of components. For example, how much of
the total variance is shown by the variance of the 20 columns – if,
say, 80% then they are important. This data could also be shown in
a Pareto chart. Note that once the first Principal Component (PC1) is
identified, the most important feature could be identified as the one
with the highest absolute value in the eigenvector corresponding to
PC1.

5.2  Cluster analysis

Cluster analysis is a data mining technique that partitions a large
number of observations into a small number of groups. Cluster
analysis partitions the dataset into groups called clusters such that
observations within a cluster are similar to each other and
dissimilar to other clusters. The clustering algorithm creates the
clusters by identifying the patterns in the data. The algorithm uses
a distance metric to find the similarity and dissimilarity in the
observations.

  Cluster analysis can be used in scenarios where grouping is the
main task at hand. Cluster analysis can be used to group real-world
entities such as projects, individuals, countries, states, vehicles, etc.
to create homogeneous groups. It can be used prior to performing
predictive analytics to identify subsets of records that display
different patterns or can be used standalone to just identify the
homogeneous segments in a dataset. After creating the clusters,
the cluster characteristics describe the different types of groups
that exist in the data.

  Two popular cluster analysis techniques are the K-means and
the hierarchical cluster analysis. We discuss the two techniques in
detail in the following sections.

5.2.1  K-means cluster analysis

K-means cluster analysis partitions the observations (rows) in a
dataset into a predefined number of “k” clusters. The observations
within a cluster have similar characteristics and are homogeneous
in nature. In k-means clustering, the number of clusters “k” must
be specified prior to performing the analysis. We can experiment
with different values of “k” until we get an anticipated result. A
desired result may be the one that creates clusters with
characteristics that are in accordance with theory, practice, or prior
knowledge. One downside of the K-means cluster analysis method
is that it does not work with categorical data. Instead, we can use
the k-medoids clustering method when we have categorical data.

  The K-means algorithm uses an iterative process to assign
observations to the clusters. It initially starts with assigning random
k observations as initial cluster centroids. It uses a distance
measure (Euclidean distance) to find similarity in the observations.
It assigns the remaining observations to the clusters by calculating
the distance metric between the cluster centroid and the
observations. The observations are clustered by identifying the
closest cluster center. The algorithm recalculates the cluster
centroid (mean of the cluster) from the newly formed clusters and
uses it as the new cluster centroid and the observations are
reassigned. This process repeats until the overall deviation (average
sum of square distance of the observations from the centroid)
within a cluster is minimum. The clustering results will depend on
the initial cluster centers that are randomly chosen. Variables of
different scales will also have an impact on the result. Hence, it is a
good practice to standardize the variables to make the variables
comparable.

5.2.3  K-medoids method (Partitioning Around Medoids)
on categorical data with R

One major disadvantage of k-means clustering is that it does not
work with categorical data. An alternative to incorporating
categorical data is to use the k-medoids method. A commonly used
k-medoids algorithm is Partitioning Around Medoids (PAM). The
PAM method partitions the observations into a predefined k
number of homogeneous clusters. It works on similar lines to the k-
means algorithm, but the difference lies in the way the cluster
centroids are calculated. Instead of the cluster center being the
mean of a cluster, the center is one of the observations in the
cluster. The cluster centers are called medoids. The K-medoid
algorithm determines the cluster configuration such that the overall
deviation of the observations in a cluster from the medoid is
minimum. A medoid of a cluster is an observation whose distance
to the other observations in a cluster is the smallest.
