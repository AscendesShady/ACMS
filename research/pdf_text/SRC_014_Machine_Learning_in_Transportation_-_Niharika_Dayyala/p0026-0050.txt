  Hypothesis testing: A hypothesis is a predictive statement capable
of being tested by scientific methods and approaches. It tries to relate an
independent variable with a dependent one. The hypothesis statements
are tested on the basis of a probability or p-value, as discussed in the
following sections.

  There are two types of hypotheses: null hypothesis (H0) and
alternative hypothesis (HA). If the statistical analysis of the data proves
that the null hypothesis can be rejected, then the alternative hypothesis
is accepted.

  For example,
  Ho : μ = μ0

  HA : μ ≠ μ0

The level of significance (LOS) and confidence interval (CI) are
relevant in hypothesis testing. Out of 100 times, if we prove something 95
times, the LOS (denoted by α) is 0.05 or 5%, and the CI is (1 – α) = (1 –
0.05) = 95%. For two-tailed tests with 5% significance, α = LOS/2 = 0.05/2 = 
0.0025.

  The p-value is the probability of obtaining results as significant as the
observed results of a statistical hypothesis test, believing that the null
hypothesis is precise. For α = 0.05, the p-value should be <0.05, to accept
the hypothesis.

  In making conclusions from hypothesis testing, there can be two
types of errors: Type I and Type II errors, as explained in →Figure 1.13.

2.1  Introduction

In this chapter, we focus on the preliminary steps for machine
learning including getting the software, loading the data, exploring
the data, cleaning the data, transformation, and data visualization.

  The process of exploring, cleansing, and transforming data is
called “data wrangling.” It is one of the essential steps a
transportation data analyst needs to perform prior to performing
data analysis. The data wrangling process enriches transportation
data to support further data analysis. It improves the quality of
data, which in turn helps extract true insights from the data.
Although data wrangling is a time-consuming activity, it can bring
forth the true power of data.

  Data visualization is a great technique that reveals hidden
insights in the data through visual diagrams. In this chapter, we
explore different data visualizations that can be created using
transportation datasets.

2.1.1.1  Loading data from CSV or Excel to MATLAB

To open a CSV file (cvs_file.csv) from the current directory, use the
following MATLAB code:

csvFileName = 'csv_file.csv';
csvData = readtable(csvFileName);

To open an Excel file (excel_file.xlsx) from the current directory, use
the following MATLAB code:

excelFileName = 'excel_file.xlsx';
excelData = readtable(excelFileName);
