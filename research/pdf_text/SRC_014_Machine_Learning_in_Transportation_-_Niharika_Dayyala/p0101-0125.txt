3.2  Accuracy for classification

3.2.1  Confusion matrix

A confusion matrix is a table that summarizes the performance of
a classification algorithm. It has four entries:

  True positive (TP): Instances correctly predicted as positive.
  True negative (TN): Instances correctly predicted as
  negative.
False positive (FP): Instances incorrectly predicted as positive
(type I error).
False negative (FN): Instances incorrectly predicted as
negative (type II error).

3.2.2  Accuracy

Accuracy is a measure of the overall correctness of the model and
is calculated as the ratio of correctly predicted instances to the
total instances:

Accuracy =  TP + TN
  TP + TN + FP + FN

3.2.3  Precision

Precision is the ratio of correctly predicted positive observations to
the total predicted positives. It measures the accuracy of the
positive predictions:

  Precision =  TP
  TP + FP

3.2.4  Recall (sensitivity or true positive rate)

Recall is the ratio of correctly predicted positive observations to
the total actual positives. It measures the ability of the model to
capture all positive instances:

  Precision =  TP
  TP + FP

3.2.5  F1 score

The F1 score is the harmonic mean of precision and recall. It
provides a balance between precision and recall and is particularly
useful when the class distribution is imbalanced:
F 1 score = 2 ×  Precision ×Recall
  Precision+Recall

4.1  K-nearest neighbors

The KNN method is a popular supervised data mining technique used for both
classification and numerical prediction, being more popular with classification.
It is a data mining technique that predicts the outcome of a target variable by
identifying the most similar K number of observations in the dataset. In a
classification problem, the predominant class of the target variable among the
KNN is assigned as the predicted value for a new record. In the case of
numerical prediction, the average of the target variable of the most similar K
observations is assigned as the predicted value for a new record. KNN method
does not have any assumptions about the target variable or the relationship
between the target and predictor variables. It is the simplest yet most
frequently used data mining technique.

  The major components of the KNN algorithm are the similarity measure
between two observations and the number of KNN to be used for prediction
purposes. The similarity measure is used to identify the nearest neighbors. It is
the distance between the observations that is calculated using Euclidean
distance. Since variables may be measured on different scales, it is good
practice to standardize the variables to bring them to a comparable scale prior
to the analysis. Standardizing the variables ensures that one variable does not
dominate the other variables due to differences in scales. The KNN algorithm
identifies the number K such that the predictive accuracy is the maximum. The
K value can range between 1 and n, where n is the number of observations. A
very low or very high value of K may lead to imperfect predictions. The value
for K = 1 makes the predictions highly sensitive to one closest observation.
Similarly, a very high value of K will simply assign the majority class of the
dataset for all the new records. Hence, the analysis is repeated with different K
values to identify the best K.
4.1.1  Classification with KNN in R

In a classification problem, the dataset is split into two partitions: the training
and the testing datasets. The training dataset with the target variable (with
classes more than or equal to 2) and the set of predictors will be used to
identify the best K, which achieves maximum predictive accuracy. The testing
dataset will give a more optimistic predictive accuracy of the selected K. The
training dataset will then be used to predict the unknown classes of the new
records using the majority outcome rule, where the majority class of the KNN
is assigned as the predicted value of the new record.

  The figure below (→Figure 4.1) explains the KNN with an example. Variable

closest three neighbors of a new record (identified by the black dot) that need
to be predicted have a majority outcome as N with one Y and two N values.
Based on the majority rule, the outcome of the new record is identified as N.
